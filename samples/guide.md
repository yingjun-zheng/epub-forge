# Epub Forge 使用指南

一份面向新用户的快速上手指南，覆盖**安装**、**转换**与**高级选项**。

## 一、安装

### 1.1 安装依赖

```powershell
python tools/fetch_deps.py
```

> 提示：`fetch_deps.py` 不依赖 pip，直接通过 PyPI 官方 API 下载与当前 Python
> 兼容的 wheel 包。所有依赖会被解压到项目根目录的 `.deps/` 文件夹。

### 1.2 启动程序

```powershell
python run.py
```

## 二、基本转换

打开界面后，把源文档**拖进窗口**，程序会自动：

1. 解析文档内容；
2. 识别章节标题并自动分章；
3. 在右侧预览章节列表。

确认无误后点击「生成 EPUB」即可。

## 三、支持的格式

| 格式 | 扩展名 | 分章依据 |
| ---- | ------ | -------- |
| 纯文本 | .txt | 正则探测（第X章等） |
| Markdown | .md | `#` 标题 |
| 网页 | .html | `h1`~`h6` |
| Word | .docx | 「标题 N」样式 |
| PDF | .pdf | 书签/字号 |

## 四、常见问题

**Q: PDF 是扫描件，转出来没有文字？**
A: 扫描件需要先做 OCR，Epub Forge 目前只处理带文字层的 PDF。

**Q: 自定义分章怎么用？**
A: 选择「自定义正则」模式，填入如 `^第[0-9]+章` 的正则表达式即可。
